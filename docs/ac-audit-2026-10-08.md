## Fixed in this branch

- **4.2.3, 4.6.3, 4.8.4:** the public map had no filter controls.
  - The filter panel was removed in the August QA pass, which left *Follow-up needed* reachable only through a deep link, and *Resolved sightings* not reachable at all.
  - The reports list now has a *Plant* picker, *Follow-up needed* and *Resolved sightings* toggles, and *Clear filters*.
  - The pins, the list and the live count all follow these filters. Covered by `e2e/map-filters.spec.ts`.
- **4.6.1:** the map legend now names the follow-up grey: "Removal reported · Follow-up needed".
- **6.1.6:** the adopted-area activity page now shows the non-exclusive bookmark wording.
- **6.2.1:** the page is now titled **My adopted areas**.
- **6.1.4 (UX):** place detail now shows "Adopted for monitoring" on return visits, not only right after the tap.
- **6.2.2:** "removal reports in the last 30 days" now uses the date of the removal report, not of a later follow-up event.
- **Robustness:** one withdrawn place no longer breaks the whole adopted-area list.
- **7.2.3:** the plant filter only offers plants that have compatible habitat in the place, so picking one never empties the map.
- **7.3.2:** e2e guard added against probability, score, rank or "high-priority" wording.
- **8.1.2:** source answers now open with "Your scan matched *X*. Here is what the approved sources say about it."
- **8.1.3:** when *Simpler* or *More detail* cannot change the approved wording, the panel now says so instead of silently repeating the answer.
- **9.6.5:**
  - The pre-filled generic safety notes no longer count as a stated permission basis.
  - Publishing now requires safety notes.
- **9.1.2 robustness:** one event with a withdrawn place no longer takes down `GET /events`.
- **9.6.3:** re-sending an unchanged `place_id` no longer refreshes the stored geometry version.
- **9.2.1 / 9.5.1:** multi-day events show their end date on the detail and summary pages.
- **3.2.1:** the guidance section is titled **Prevent accidental spread**.
- **Mobile navigation:** the bottom bar is now symmetric, with two destinations either side of Scan (Map, Plants | Scan | Records, Events). *My adopted areas* moved to the profile and Places pages; the desktop sidebar keeps every item.
- **Copy:** the private-access landing page no longer claims recovery codes "work only once"; they are currently reusable.

## Decisions needed (code and AC disagree on purpose or need a product call)

1. **2.1.1 / 2.1.2 recovery codes.** The AC asks for ten one-time codes. The app issues one reusable code. Change the code (migration plus copy) or reword the AC.
2. **2.3.1 duplicate check.** `render.yaml` sets `SCREENING_DISABLE_DUPLICATE_CHECK=true` in production, so exact duplicates are not rejected live. Turn it back on, or record the deviation.
3. **3.3.4, 4.1.2, 4.5.3 GPS limits.** These ACs say 250 m; the app uses 350 m for reports, removal and location context (team decision, 2026-10-02).
   - 4.1.2 also expects submit to be disabled above the limit. The app warns instead, and the report later returns as *needs rescan*.
4. **1.1.2 / 1.1.3.** The AC asks to show the confidence %, and to label low-confidence results "Uncertain". The app hides the % and says "Photo needs another try". Both are usability choices.
5. **4.5.1 regrowth.** After *Regrowth present*, a sighting cannot be marked removed again: a unique removal-event index blocks it, so the button is hidden. Fixing this needs a migration.
6. **9.5.1.** Event summaries exclude *merged* (same-person near-duplicate) reports. Should they count?
7. **9.7.5.** A host can restore their own hidden event immediately; the AC says an appeal "reopens review". Accept self-restore, or add a review state.
8. **Epic 8 in production.** With Gemini off, *Simpler* rarely changes the text, and free-form "why", "if" and component questions are refused.
   - Enabling the judge and generation in Render closes 8.1.3, 8.1.5, 8.2.3 and 8.3.2.
   - Alternative: add reviewed `direct_support` relations to the knowledge pack.
9. **5.1.1 / 6.1.2 trails.** Trails are hidden from public discovery and from the adopt prompt (presentation patch). The ACs include trails.
